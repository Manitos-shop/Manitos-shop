📦 Publicación guiada · V6.9

Tus cambios locales no se pierden al abrir esta guía.
1. Pulsa ⬇️ Descargar JSON para crear el catalogo.json actualizado.
2. En GitHub abre el archivo catalogo.json original.
3. Reemplaza el contenido con el archivo nuevo o súbelo como reemplazo.
4. Haz Commit directly to main.
5. Regresa aquí y toca 🌐 Actualizar desde servidor.
Consejo: si Android lo renombra como “catalogo (2).json”, no borres el original.
